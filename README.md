# Test Técnico - Ingeniero de Datos
**Sun Valley Investment - 2026**

## 📋 Descripción

Este repositorio contiene un test técnico para evaluar candidatos a la posición de **Ingeniero de Datos** en Sun Valley Investment.

## 🎯 Objetivo

Evaluar la capacidad del candidato para extraer, procesar y estructurar información de reportes técnicos mineros (NI 43-101) en formato PDF.

## 📁 Contenido del Repositorio

- **`data/`** - Reportes técnicos en PDF que deben ser procesados
- **`TEST_TECNICO_INGENIERO_DATOS.md`** - Instrucciones detalladas del test

## 🚀 Instrucciones para Candidatos

1. **Lee cuidadosamente** el archivo [`TEST_TECNICO_INGENIERO_DATOS.md`](TEST_TECNICO_INGENIERO_DATOS.md)
2. **Fork** este repositorio o clónalo localmente
3. **Desarrolla** tu solución según los requerimientos especificados
4. **Documenta** tu trabajo siguiendo las guías del test
5. **Entrega** tu solución mediante:
   - Un repositorio público/privado en GitHub (compartido con nosotros), **O**
   - Un archivo ZIP con todo el código

## ⏱️ Tiempo de Entrega

**2 días** desde que recibes este test
